Release Notes

Clip 的每一次更新，都为了更好的体验

v2.3.0 Latest

2026-11-20

What's new

  • MCP 全面升级：连接更简单，新增自定义端口，并支持保存、编辑、标签管理和删除。
  • 新增搜索快捷键 ⌘F，重复按下可切换筛选。
  • 暂停记录时，状态栏图标会变为暂停样式。
  • 标签支持双击重命名。

Improvements

  • 优化图片文字识别与搜索高亮，高亮位置更准确。
  • 优化搜索框、筛选和搜索建议的使用体验。
  • 优化设置界面布局，统一各页面标题样式。
  • 预览窗口尺寸会根据屏幕可用空间自动适配。
  • 链接预览加载更快，卡片滚动更流畅。
  • 修复多文件与多选拖出不完整的问题。
  • 更新应用图标与提示窗口样式，修复若干界面问题。

v2.2.0

2026-10-04

What's new

  • 窗口模式新增简洁显示，可在窗口底部切换。
  • 抽屉模式支持拖拽调整历史记录顺序，并同步到窗口模式。
  • 支持同时选择多个标签筛选历史记录。
  • 新增首次启动引导和菜单重启入口。

Improvements

  • 优化大文本与 JSON 编辑性能，支持 JSON 折叠并改进输入和语法高亮。
  • 改进 Markdown 预览、富文本背景和深色模式，优化设置布局。
  • 修复搜索标签删除、方向键导航及卡片滚动和视图残留问题。
  • 完善来源应用信息与备份恢复，修复导入排序和分类冲突。

v2.1

2026-07-30

What's new

  • 新增 JSON 编辑模式，支持格式化、压缩、转义处理、Unicode 编解码、键排序和命名风格转换。
  • JSON 编辑器新增行号、语法高亮、格式校验和缩进设置。
  • 新增 Markdown 内容识别与渲染预览，并支持在渲染结果和原文之间切换。

Improvements

  • 优化筛选按钮、搜索框、卡片选中状态及顶部工具栏的视觉细节。
  • 修复数据库索引。
  • 修复搜索联想列表的鼠标事件处理问题。
  • 修复若干卡片布局、选中边框和界面稳定性问题。

v2.0

2026-06-12

1.0 版本在 SwiftUI 框架下已趋于稳定，为了追求更极致的性能和体验，我决定对整个应用进行彻底重构。2.0 版本采用 AppKit 架构重写，在启动速度、流畅度和响应速度方面都有显著提升，带来更加流畅的使用体验。

What's new

  • 新增 MCP 支持（Beta）
  • 历史记录列表完整支持多选操作 #16
  • 支持直接拖拽文本、文件等到剪贴板
  • 更丰富的卡片菜单
  • 初步适配 macOS 27

Improvements

  • 优化识别复制的内容，比如在 IntelliJ IDEA 复制文件，现在能准确识别
  • 最低支持版本降低为 macOS 14
  • 修复了一些已知问题
